# 📊 Price Forecast System

Система для анализа, визуализации и прогнозирования цен на товары на основе исторических данных и внешних факторов.

Проект реализован в рамках выпускной квалификационной работы.

---

## 📌 Описание проекта

Приложение представляет собой интерактивную аналитическую систему, разработанную с использованием:

- Streamlit (интерфейс)
- PostgreSQL (хранение данных)
- CatBoost (модель машинного обучения)
- ETL-пайплайн (сбор и обработка данных)

Система позволяет:

- анализировать исторические данные
- строить интерактивные графики
- прогнозировать цены
- загружать новые данные
- автоматически собирать данные с сайтов
- учитывать внешние факторы (курсы валют, нефть, погода)

Используется:

- количество продаж
